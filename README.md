# KKS Analyzer

Настольная Windows-программа для проверки TXT/CFG-файлов с KKS-кодами в секциях `#IA1000` и `#ID1000`.

## Возможности

- поиск дубликатов в одном файле и сохранение копии без повторов;
- просмотр полного списка сигналов с основной частью, постфиксом, разделом и номером строки;
- пакетное выделение сигналов в полном списке (`Ctrl`, `Shift` или «Выбрать все») и сохранение копии без выбранных кодов;
- поиск сигналов без постфиксов;
- отдельная статистика постфиксов аналоговых (`#IA1000`) и дискретных (`#ID1000`) сигналов;
- сравнение двух файлов: общие сигналы и сигналы только в одном из файлов;
- фильтр общих сигналов (дубликатов между двумя файлами).
- пакетный поиск списка KKS-кодов сразу в нескольких PDF, DOCX и текстовых документах;
- переход к поиску кода двойным щелчком по строке результата анализа.
- операции над двумя файлами с сохранением в новую копию: исключение общих кодов, дополнение, объединение, пересечение и симметрическая разница.

Сравнение выполняется по полному KKS-коду без учёта регистра. Постфиксом считается текст после последнего символа `_`. Если файл содержит системные строки `#`, анализируются секции `#IA1000`/`#ID1000`. Если системных строк нет, анализируются все непустые строки.

Во вкладке «Работа с кодами» поддерживаются PDF, DOCX, TXT, CFG, CSV, LOG, MD, XML, JSON и RTF. В PDF выполняется поиск по существующему текстовому слою; для отсканированных страниц потребуется отдельное OCR-расширение.

В режиме двух файлов доступны семь безопасных операций: файл 1 или файл 2 без общих кодов, дополнение одного файла кодами второго, объединение, пересечение и симметрическая разница. Каждая операция открывает диалог сохранения и никогда не перезаписывает исходные файлы. Если оба файла имеют секции IA/ID, сформированные наборы также группируются по этим секциям; для обычных списков сохраняется простой список кодов.

## Запуск для разработки

Требуется Windows и .NET 8 SDK:

```powershell
dotnet run --project src/KKSAnalyzer.App
```

Проверки логики:

```powershell
dotnet run --project tests/KKSAnalyzer.Tests
```

## Сборка переносимой версии

```powershell
dotnet publish src/KKSAnalyzer.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

После сборки приложение находится в `publish\KKSAnalyzer.exe`. Установка .NET на компьютере коллеги не требуется. Для распространения нужно передавать всю папку `publish` (или готовый архив `KKSAnalyzer-win-x64.zip`), поскольку WPF использует несколько системных DLL рядом с EXE.
